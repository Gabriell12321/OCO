# Quarto 01

Um único quarto 3D para avaliar os gráficos: materiais PBR fotográficos, iluminação fria de janela, abajur quente, sombras e oclusão de contato. A cena tem navegação em primeira pessoa para inspeção.

Abra com `ABRIR QUARTO.cmd` na pasta acima ou execute `npm start` nesta pasta e visite `http://127.0.0.1:4173`.

- Arraste com o mouse para olhar.
- Use WASD ou as setas para caminhar.
- O botão com seta circular restaura a posição inicial.
- O botão ao lado abre tela cheia.
- No celular, arraste para olhar e use os direcionais.

Three.js e todas as texturas estão incluídos localmente. O projeto não depende de CDNs durante o uso. As fontes e licenças dos materiais estão em ASSETS.md e o crédito de Three.js está em dist/vendor/THREE-LICENSE.txt.
